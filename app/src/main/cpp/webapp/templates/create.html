Accepted puzzle file format (.txt)

Matches instances/curated-dataset: line 1 = order (3 / 4 / 5), line 2 = id (e.g. 0), then n² rows of n² integers, -1 = empty. Lines starting with # are ignored.

3
0
-1 -1  5 -1 -1 -1 -1 -1 -1
8 -1 -1 -1 -1 -1 -1  2 -1
...

9×9: values 1–9. 16×16: 1–10 → symbols 0–9; 11–16 → a–f. 25×25: 1–25 → a–y. You can Save as .txt after validation.

Fill in the clues (empty cells will be for the player to solve). The server checks the puzzle is solvable (default solver settings, 120 s) before export or play.
