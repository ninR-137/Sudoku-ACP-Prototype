Upload puzzle

Load a puzzle from a .txt file (same layout as instances/curated-dataset), then open it in Game Mode or Experiment Mode.

Accepted puzzle file format (.txt)

Plain text, UTF-8. Lines that start with # are treated as comments and ignored (useful if you saved a progress file that contains two blocks). A contiguous run of values after the header must contain at least N² × N² integers (N = order²); extra numbers from a second block in the same file are not used.

<order>          ← 3 = 9×9, 4 = 16×16, 5 = 25×25
<idum>           ← integer (often 0), ignored by the web app
<n² rows of n² integers>   ← -1 means empty cell

Example (order 3, partial):
3
0
-1 -1  5 -1 -1 -1 -1 -1 -1
8 -1 -1 -1 -1 -1 -1  2 -1
...

Value encoding (how numbers map to digits in the grid):

  • 9×9: use 1–9 for clues, -1 for blanks.
  • 16×16: 1–10 for symbols 0–9, 11–16 for a–f; -1 empty.
  • 25×25: 1–25 map to a–y; -1 empty.
