About SudoPHASE

Parallel Ant Colony + Simulated Annealing — Sudoku solver, experiments, and play.

User manual

This web application lets you load Sudoku puzzles (9×9, 16×16, 25×25), play them, run the research solver with configurable parameters, create your own puzzles, and import/export puzzles as text or PDF.

Main menu

  • Game Mode — Full-screen play: choose a puzzle, enter digits, undo, clear, optional computer solve with default settings, exports.
  • Experiment Mode — Same grid plus a side panel: puzzle library, full solver parameters, SOLVE PUZZLE / Stop, and a Download dialog (Initial/Progress × TXT/PDF).
  • Create Puzzle — Paint clues on the board. The server verifies the puzzle is solvable within 120 seconds using default solver parameters. Only then can you save a .txt or jump to Game / Experiment Mode. Optional “Save locally” stores the puzzle in your browser for the library.
  • Upload Puzzle — Page with the accepted file format; pick Game Mode or Experiment Mode, then choose a .txt file.
  • About Game — This manual.

Exports and uploads

  • Game Mode — In Choose puzzle, set Source to Upload .txt file and pick your file. Next to Stop, Download opens a dialog: export Initial puzzle (clues only) or Progress (initial + current grid), as .txt or .pdf.
  • Experiment Mode — A Download button (below Stop) opens the same dialog style as Game Mode: Initial puzzle or Progress, as .txt or .pdf. Upload is available via Upload .txt.
  • File layout matches instances/curated-dataset. Lines starting with # are ignored when loading; extra data after the first full grid may be ignored.

How to play — Game Mode

Game Mode is for solving by hand (with optional help from the solver). Typical flow:

  1. Click Choose puzzle: pick size and source (curated, Created puzzles, or Upload .txt file). For library sources, select an instance and Load. For upload, use Choose .txt file. Clues are fixed and the timer starts.
  2. Select a cell (border highlight). Peer cells (same row, column, block) are highlighted. Type with the digit buttons — only non-fixed cells change. The app may auto-advance to the next empty cell.
  3. Use Undo to revert the last edit. Clear resets to an empty board (same size).
  4. Illegal duplicates show in red until fixed.
  5. Solve runs the solver on the original clue puzzle (not only your current entries). Stop cancels a running solve.
  6. Use Download (beside Stop) to export Initial or Progress as .txt or .pdf. After a successful solve, the grid is complete—choose Progress to capture the filled board plus the initial clues.
  7. When every cell is valid and filled, you see Puzzle solved! with your elapsed time.

Experiment Mode (brief)

  • Left panel: Source (curated / created), Size, instance list, Load selected, delete for created entries.
  • Parameters — Timeout, ants, evaporation, SA temperatures, SA frequency (0 disables SA), cooling rate, thread count, communication settings. Evaporation and cooling must be strictly between 0 and 1 (popup if not).
  • SOLVE PUZZLE solves the loaded clue puzzle. Stop cancels the job.
  • Download (left panel) uses the same options dialog as Game Mode: choose Initial or Progress, and choose TXT or PDF.
  • Upload .txt (under the grid) loads a puzzle file directly into the board.

Rules of Sudoku

Fill the grid so that every row, column, and block contains each symbol exactly once. Clues are fixed. Sizes: 9×9 (digits 1–9), 16×16, 25×25 with the symbol sets used in the app.

Tips

  • Hard instances may need a longer Timeout or more Thread Count in Experiment Mode.
  • Created puzzles must pass server validation — unsolvable or timeout failures are rejected.
  • Theme toggle (top right) is remembered per browser.
